## Publicar
1. Subir los archivos de esta carpeta a la raíz del repositorio GitHub.
2. Vercel → Add New → Project → importar repositorio.
3. Framework: Other; Build Command: vacío; Output Directory: vacío (raíz).
4. Deploy.
